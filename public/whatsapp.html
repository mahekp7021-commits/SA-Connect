What must be configured on the server

Meta requires META_APP_SECRET, META_WEBHOOK_VERIFY_TOKEN, and META_CREDENTIAL_ENCRYPTION_KEY. OpenWA requires its base URL, API key, webhook secret, and PUBLIC_API_BASE_URL. The platform admin should configure these in Render environment variables.

Official Meta API and OpenWA use separate endpoints, separate channel labels, and separate credentials. Incoming messages are written into the same tenant-isolated CRM Inbox collections with their provider recorded.
