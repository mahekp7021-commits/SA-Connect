Server setup checklist

Render backend must have PUBLIC_API_BASE_URL, OPENWA_BASE_URL, OPENWA_API_KEY, OPENWA_WEBHOOK_SECRET, META_APP_SECRET, META_WEBHOOK_VERIFY_TOKEN, and META_CREDENTIAL_ENCRYPTION_KEY configured as needed. Do not put API keys in Android source code.

Official Meta API is the official provider. OpenWA API and OpenWA QR use an unofficial WhatsApp Web bridge and may carry session/account restrictions.
